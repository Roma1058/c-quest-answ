<details>
  <summary>1. У чому полягають основні принципи ООП?</summary>
  - **Спадкування (Inheritance)**: Цей принцип дозволяє створювати нові класи на основі існуючих класів, спадковуючи їх властивості і методи. Спадкування сприяє відновленню коду, покращенню відновленості та зменшенню дублювання коду.
Інкапсуляція (Encapsulation): Інкапсуляція вказує на обмеження доступу до деяких властивостей і методів класу і забезпечує їх захист від зовнішнього втручання. Властивості класу повинні бути приховані від прямого доступу, і доступ до них повинен бути регульованим за допомогою геттерів та сеттерів.

Поліморфізм (Polymorphism): Поліморфізм дозволяє використовувати однаковий інтерфейс для об'єктів різних класів. Це означає, що однакові методи можуть виконувати різні дії залежно від класу об'єкта, який їх викликає. Поліморфізм підвищує гнучкість програм та дозволяє легше додавати новий функціонал.

Абстракція (Abstraction): Абстракція полягає в прихованні деталей реалізації і наданні користувачам можливості використовувати об'єкт чи клас, не знаючи всіх його технічних деталей. Абстракція дозволяє спростити складність системи та концентруватися на важливих аспектах.

Спільнота (Association): Цей принцип вказує на взаємодію об'єктів та їх спільне використання. Об'єкти можуть бути пов'язані між собою через асоціації, композиції та агрегації для досягнення більшого рівня функціональності.

Наслідування (Polish object inheritance): Цей принцип включає в себе узагальнення загальних частин коду для зменшення повторення та забезпечення більшої структурованості програми.

</details>
